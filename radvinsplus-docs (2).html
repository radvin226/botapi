📦 نصب و راه‌اندازی

پیش‌نیاز: Python نسخه 3.10 یا جدیدتر.

۱. نصب از PyPI

bash
# نصب نسخه مشخص از PyPI
python -m pip install --upgrade radvinsplus==1.0.0

  • نام بسته: radvinsplus · نسخه: 1.0.0 · لایسنس: MIT

🚀 ساخت اولین ربات

یک فایل به نام bot.py بساز:

python · bot.py
import os
from radvinsplus import Bot

bot = Bot(os.environ["SPLUS_BOT_TOKEN"])

@bot.command("start")
def start(ctx):
    ctx.reply("سلام! ربات با radvinsplus فعاله.")

@bot.command("help")
def help_command(ctx):
    ctx.reply("یک پیام متنی بفرست تا دریافتش کنم.")

bot.run_polling()
⚠️ امنیت توکنتوکن را داخل کد قرار نده. آن را در متغیر محیطی SPLUS_BOT_TOKEN نگه دار.
powershell
$env:SPLUS_BOT_TOKEN="YOUR_TOKEN"
python bot.py
bash
export SPLUS_BOT_TOKEN="YOUR_TOKEN"
python3 bot.py
  1. فایل bot.py را بساز و کد بالا را در آن بگذار.
  2. توکن ربات را در متغیر محیطی تنظیم کن.
  3. فایل را اجرا کن و در سروش‌پلاس به ربات پیام /start بده.

🧪 محیط تمرین

کد را اینجا ویرایش کن و توکن ربات را وارد کن تا در کد جایگزین شود. همه‌چیز فقط داخل همین صفحه و روی دستگاه خودت می‌ماند.

۱. توکن ربات

۲. کد (قابل ویرایش)

🔐 امنیت توکن — حتماً بخوان
  • توکن، کلید کنترل کامل ربات است. هرکس آن را داشته باشد می‌تواند ربات را بگیرد؛ آن را با هیچ‌کس به اشتراک نگذار.
  • این صفحه توکن را در هیچ حافظه‌ای (localStorage یا سرور) ذخیره یا ارسال نمی‌کند؛ با بستن یا رفرش صفحه پاک می‌شود.
  • در کد نهایی‌ات توکن را هاردکد نکن؛ از متغیر محیطی SPLUS_BOT_TOKEN استفاده کن.
  • اگر توکن لو رفت، فوراً آن را از پنل ربات باطل و توکن جدید بگیر.
  • کد حاوی توکن را در Git، اسکرین‌شات یا پیام عمومی منتشر نکن.

⚡ شروع سریع (نمونه رسمی PyPI)

این نمونه مستقیماً از README بسته رسمی در PyPI گرفته شده و ترکیب دستور، فیلتر متنی و پاسخ را نشان می‌دهد.

python
from radvinsplus import Bot, Filters

bot = Bot("YOUR_SOROUSH_BOT_TOKEN")

@bot.command("start")
def start(ctx):
    ctx.reply("سلام! ربات آماده است.")

@bot.on_message(filters=Filters.text)
def echo(ctx):
    if ctx.command is None:
        ctx.reply(f"گفتی: {ctx.text}")

bot.run_polling()
⚠️توکن را در کد عمومی یا Git قرار نده؛ از متغیر محیطی استفاده کن.

from radvinsplus import Bot, Filters
bot = Bot("TOKEN")

@bot.on_message(filters=Filters.text & Filters.private)
def private_text(ctx):
    ctx.reply("پیام متنی خصوصی دریافت شد")

@bot.on_message(filters=Filters.photo | Filters.video)
def media(ctx):

bot.run_polling()

🧭 Router و ساختار پروژه

برای پروژه‌های بزرگ، هندلرها را در Router جداگانه ثبت کن و سپس به Bot متصل کن.

python
from radvinsplus import Bot, Router

bot = Bot("TOKEN")
account = Router("account")

@account.command("profile")
def profile(ctx):
    ctx.reply(f"شناسه: {ctx.user_id}")

bot.include_router(account)
bot.run_polling()

Router از message، command، callback_query، edited_message و update پشتیبانی می‌کند.

🪄 دکمه‌های شیشه‌ای

برای ساخت دکمه شیشه‌ای از InlineKeyboard و InlineButton استفاده کن.

python
from radvinsplus import Bot, InlineKeyboard, InlineButton
bot = Bot("TOKEN")

@bot.command("start")
def start(ctx):
    menu = (InlineKeyboard()
        .row(InlineButton.callback("وضعیت", "status"),
             InlineButton.callback("راهنما", "help")))
    ctx.reply("یکی را انتخاب کن:", reply_markup=menu)

@bot.on_callback_query
def callbacks(ctx):
    data = ctx.callback_query.get("data")
    if data == "status":
        ctx.answer_callback("ربات فعاله")
    elif data == "help":
        ctx.answer_callback("دستور /help را بفرست")

bot.run_polling()
⚠️ محدودیتداده callback حداکثر ۶۴ بایت UTF-8 است.

برای لینک مستقیم از InlineButton.url(text, url) استفاده کن.

⌨️ کیبورد پاسخ

کیبورد پاسخ در محل ورودی پیام نمایش داده می‌شود.

python
from radvinsplus import ReplyKeyboard, remove_keyboard

keyboard = ReplyKeyboard(resize=True, one_time=False)
keyboard.row("پروفایل", "راهنما")
keyboard.add("ارسال موقعیت", request_location=True)
ctx.reply("از منو استفاده کن:", reply_markup=keyboard)

# حذف کیبورد
ctx.reply("کیبورد حذف شد", reply_markup=remove_keyboard())
⚠️ توجهدر add می‌توان از request_contact=True یا request_location=True استفاده کرد؛ هر دو را هم‌زمان برای یک دکمه فعال نکن.

🖼️ فایل و رسانه

در Context متدهای reply_photo و reply_document در دسترس‌اند. در Client نیز متدهای API مثل send_photo، send_video، send_audio، send_document و send_media_group قابل فراخوانی‌اند.

python
from radvinsplus import Bot, InputFile
bot = Bot("TOKEN")

@bot.command("file")
def send_file(ctx):
    file = InputFile("./sample.pdf")
    ctx.reply_document(file, caption="فایل نمونه")

bot.run_polling()
📥 دانلود فایلbot.download_file(file_id) بایت‌ها را برمی‌گرداند و با destination= روی دیسک ذخیره می‌کند؛ سقف ۲۰ مگابایت است.
📎 منابع ورودیInputFile از مسیر فایل، بایت یا file object پشتیبانی می‌کند. برای ارسال مجدد فایل موجود، استفاده از file_id مناسب است.

🛡️ خطاها و امنیت

با @bot.on_error خطاهای هندلرها را مدیریت کن.

python
from radvinsplus import Bot, APIError, NetworkError
bot = Bot("TOKEN")

@bot.on_error
def errors(ctx, error):
    if isinstance(error, APIError):
        print(error.error_code, error.description)
    elif isinstance(error, NetworkError):
        print("مشکل شبکه:", error)

bot.run_polling()

نکات امنیتی

  • توکن را در سورس عمومی، مخزن Git یا لاگ‌ها قرار نده.
  • توکن را همیشه از متغیر محیطی بخوان.
  • URL وب‌هوک و مسیر محرمانه آن را عمومی نکن.
  • خطاها را ثبت کن، اما اطلاعات محرمانه را لاگ نکن.
  • بسته را فقط از PyPI رسمی نصب کن و با pip install radvinsplus==1.0.0 نسخه مشخص بگیر.
  • نسخه 1.0.0 در PyPI «Provenance» (گواهی منشأ و Trusted Publishing) ندارد؛ پس هش فایل را بررسی کن: SHA-256 به‌صورت ef90b58a…fac38a0 است.

🌐 Polling و Webhook

Long Polling

python
bot.run_polling(timeout=25, limit=100)

برای توقف از Thread دیگر می‌توان bot.stop() را صدا زد. به‌صورت پیش‌فرض، پیش از شروع Polling وب‌هوک قبلی حذف می‌شود؛ برای تغییر این رفتار از delete_webhook=False استفاده کن.

Webhook

python
secret = "LONG_RANDOM_SECRET"
bot.set_webhook(url="https://example.com/hook/" + secret)
bot.serve_webhook(
    host="127.0.0.1",
    port=8080,
    path="/hook",
    secret=secret,
    block=True,
)
⚠️ نکته استقرارسرور داخلی HTTP است. برای دسترسی عمومی، HTTPS را با Reverse Proxy (مثل Nginx یا Caddy) فراهم کن. وب‌هوک باید از اینترنت قابل دسترسی باشد.

📚 نسخه و محدودیت‌ها

مشخصات نسخه 1.0.0 کتابخانه.

  • نیازمند Python 3.10 یا جدیدتر (Requires-Python >=3.10)
  • لایسنس MIT
  • هسته بدون وابستگی Runtime ثالث
  • پشتیبانی از Long Polling و Webhook
  • هندلرهای پیام، Callback Query، پیام ویرایش‌شده و Update عمومی
  • Router و فیلترهای آماده/ترکیبی
  • سازنده Inline و Reply Keyboard
  • ابزارهای InputFile و InputMedia
⚠️ نکته سازگاریپیاده‌سازی بر اساس مستندات Bot API سروش‌پلاس انجام شده است. بعضی متدها در سند مبنا «به‌زودی» معرفی شده‌اند؛ بنابراین وجود متد در کتابخانه به معنی فعال بودن قطعی آن در سرور نیست.
